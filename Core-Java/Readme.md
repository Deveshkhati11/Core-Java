# ☕ Java Core

A structured repository for learning and mastering **Core Java**, covering fundamental concepts, object-oriented programming, collections, exception handling, multithreading, Java 8+ features, JVM concepts, and other essential Java topics.

The goal of this repository is to build a strong foundation in Java for **backend development, Spring Boot, DSA, and technical interviews**.

## 🛠️ How to Use This Repository

Clone the repository:

```bash
git clone https://github.com/Deveshkhati/java-core.git
```

Navigate into the project:

```bash
cd java-core
```

Each topic contains Java examples and practice code designed to demonstrate the underlying concept.

The recommended approach is:

```text
Learn → Understand → Code → Experiment → Practice → Revise
```

Because apparently reading 47 articles about inheritance without writing a single subclass does not count as learning.
